FEATURE STATUS / UNDER REVIEW

FLIGHT ASSISTANT IS OFF

Designed to assist.
Waiting for clearance.

Flight Assistant is disabled for every aircraft in the current app. A saved profile or HOTAS binding cannot turn it on. The project is awaiting a response from Gaijin's legal team before this feature is enabled for users.

How the proposed feature works

  1. Read the flight state. It would use War Thunder's local flight telemetry and the pilot's physical stick input.
  2. Assist the controls. The design can apply bounded corrections through the configured virtual axes while spring-centered controls return, and use the game's own trim command where appropriate.
  3. Check eligibility. The initial design targets eligible aircraft profiles and restricts operation by flight conditions. The behavior may change or be removed after legal review.

This describes a disabled, experimental design. It is not an available control mode or a promise of release.

One controls setup.
A different feel for every plane.

VTrim reads War Thunder's local telemetry to identify the aircraft you are flying. Once identified, it creates a profile if one does not exist and switches to that aircraft automatically. You can also add and tune a plane manually before your first flight.

01 / DEFAULT

Start with shared controls

02 / CUSTOM

Tune each aircraft

Switch a plane to Custom to save its own trim, bindings and pitch, roll and yaw curves. Tailor props, early jets and top-tier jets inside one War Thunder controls profile.

03 / IN GAME

Route axes through vJoy

Bind War Thunder's pitch, roll and yaw controls to the corresponding vJoy axes. Set the game's axis response, curves and deadzones to neutral/default values so VTrim handles the shaping once.

HOTAS SWITCH GUIDE

A real switch needs
the right kind of input.

War Thunder's gear command behaves like a momentary button. A two-position hardware switch stays ON or OFF. The Assistant can turn each position change into one short command.

DIRECT GAME BINDING

Normal toggle behavior

SWITCH ONGame sees a pressed button
SWITCH OFFButton is released; no second gear press

Because the ON position stays held, returning from Escape or another menu can make the game see it again. That may toggle the gear unexpectedly.

ASSISTANT EDGE MAPPING

One tap per position

SWITCH ONTap G once → gears up*
SWITCH OFFTap G once → gears down*

The configured Gear switch shown below maps both physical positions to G. You can also use the same virtual button for both edges and bind that button to Gear in game.

* Example assumes the game begins with gear down and the switch and game are in sync. This is a toggle command; the app does not read the aircraft's actual gear position.

!
With a direct game binding, do not leave the switch ON across Escape.

A held ON input can retrigger when you return to flight. Remove that native binding when using Assistant mapping. In this gear example, moving to OFF taps G and lowers the gear, so make that move only when it is safe.

HOW THE CONTROLS WORK

Built for pilots.
Clear about the rules.

Fair play guides the app. Its enabled features focus on adjustments to the player's experience: VR comfort, physical control mapping, trim and axis feel. We review their behavior against War Thunder's published rules and respond to guidance from Gaijin.

01 / VR COMFORT

Neck Assistant

Designed as an accessibility and comfort aid for pilots with disabilities or neck pain, and for anyone who wants an easier way to check behind in a dogfight. It adjusts the VR view through the VR runtime, using an OpenXR layer with OpenXR, VDXR or SteamVR setups, rather than changing War Thunder's game files.

That approach aims to work with the game's normal VR view. It cannot guarantee anti-cheat acceptance or prevent physical discomfort; use settings that feel comfortable for you.

02 / PHYSICAL CONTROLS

Advanced Switches

Many HOTAS and throttle switches stay in a position, while War Thunder expects a momentary button press. A simple position mapping turns the pilot's physical ON or OFF movement into one button action, so each position can use the game's existing command.

The app also contains configurable multi-step and repeat actions. Those need separate review; we do not claim every switch configuration is equivalent to a single button press.

03 / PER-AIRCRAFT FEEL

VTrim & curves

War Thunder already offers trim and axis tuning. VTrim adds a more convenient place to save pitch, yaw and roll response curves and trim preferences for different aircraft, then routes physical controls through a vJoy virtual controller.

Joystick Gremlin and Universal Control Remapper are other physical-to-virtual controller tools. Their existence does not mean Gaijin has approved VTrim or every virtual-device behavior.

Our policy

Our goal is fair play: the enabled tools adjust the player's VR and control experience while keeping the pilot in control. We aim to follow War Thunder's Terms of Service and Code of Conduct. If Gaijin identifies a concern, we will review it and revise or disable the affected feature through an app update to help protect players. Experimental features such as Flight Assistant will remain disabled unless Gaijin clears them for use.

QUICK ANSWERS

Before you fly.

Do I need a VR headset?

No. Monitor profiles, HOTAS tools, VTrim and switch mapping can be useful without VR. Neck Assistant is for VR play.

How do I bind a two-position gear switch?

Map the ON and OFF positions to one brief Gear command, then remove the direct physical switch binding in War Thunder. Start with the aircraft gear and hardware switch synchronized.

Where are the downloads and source code?

Both are on the project's GitHub page. Use its Releases section for the app.

Does the app install updates automatically?

Starting with v2.0.1, yes. It checks at launch and every six hours while open, including patch releases. A newer compatible GitHub release is installed automatically and the app restarts. If War Thunder is running, the update waits until you leave the game. Update App also lets you check immediately.

Is Flight Assistant available?

No. Flight Assistant is locked off for all aircraft while the project awaits legal clarification from Gaijin. Its proposed behavior is described in the feature status section.

How do you approach War Thunder's rules?

We design around pilot input and existing controls, review features against the Terms of Service, and respond to concerns raised by Gaijin. Experimental features remain off while they await approval.

Is this an official War Thunder product?

No. War Thunder VR Assistant is a community project and is not affiliated with or endorsed by Gaijin Entertainment.
